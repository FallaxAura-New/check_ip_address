02 / 说明

如何理解结果

获取 IP：目标接口返回的出口地址。官网有响应：仅确认 HTTPS 响应；游戏项检测官网。不支持读取：接口没有提供有效 IP。

跨域限制可能导致浏览器无法读取结果，可点“浏览器核对”查看原始响应。缺少位置时，已测得的 IP 会发送给 ipwho.is 查询；位置仅供参考。

如何核对实际代理节点？

在使用代理的设备上点“浏览器核对”，再复制域名到 Loon 等客户端的请求记录中，查看刚才连接的规则和节点。游戏对局需查看游戏运行时的连接记录。
